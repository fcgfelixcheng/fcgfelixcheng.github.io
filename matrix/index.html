            点一件事可以改内容、日期、交给谁，或换到别的格。用电脑可以直接拖到别的格。

            装到电脑桌面 / 手机主屏幕
            1. 你写的事只存在你自己的手机或电脑，别人看不到。每部设备各自一份；换手机、用无痕模式或清除浏览器资料，记录会不见。
            2. iPhone / iPad：用 Safari 打开这页 → 分享按钮 →「添加到主屏幕」。
            3. Android：用 Chrome 打开这页 → 右上角 ⋮ →「添加到主屏幕」或「安装应用」。
            4. Windows / Mac（Chrome）：右上角 ⋮ →「投放、保存和分享」→「创建快捷方式」，勾「在窗口中打开」。窗口拉小，放在屏幕一边。
            5. Windows（Edge）：右上角 ⋯ →「更多工具」→「固定到任务栏」。
            6. Mac（Safari）：菜单「文件」→「添加到程序坞」。
            7. 从 WhatsApp 点开的话，先按右上角选「用 Safari / Chrome 打开」再加。想一打开就是小窗：网址最后面加 #widget 再收藏。
